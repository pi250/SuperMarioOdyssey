# Mario Odyssey Web

Vertical slice jugable en navegador del platformer 3D de Nintendo.
Three.js + TypeScript + física cinemática propia.

## Jugá
https://TU-USUARIO.github.io/mario-odyssey-web/

## Controles
| Acción | Tecla |
|---|---|
| Mover | WASD |
| Cámara | Mouse |
| Saltar (triple salto) | Espacio |
| Lanzar Cappy | Click |
| Capturar | E |
| Dive / Ground pound | Ctrl en el aire |

## Desarrollo
```bash
npm ci
npm run dev
```

Las constantes de feel viven en `src/player/tuning.ts`. Tocá ahí, no en `Player.ts`.
